# Composition Patterns and Original Metaphors

## Basic Structure Types

Choose exactly one structure type per image; do not mix too many.

### Workflow

Best for: Input -> Process -> Output, content creation pipelines, AI workflows, automation chains.
Drawing style: Input on the left, Xiaohei or a strange machine processing in the middle, output on the right. Use orange arrows for the main flow.

### System Detail / Module

Best for: Information sources, filters, databases, renderers, local modules in an agent system.
Drawing style: Draw only 3-5 core modules, with Xiaohei participating in a key action at one node.

### Before-After Comparison

Best for: Chaos vs Order, Manual vs Automated, Scattered vs Unified, Anxious vs Stable.
Drawing style: Chaos on the left, order on the right, with a central orange arrow. The character's state can be exaggerated.

### Character State

Best for: User pain points, creator status, tool fatigue, information overload, getting unstuck.
Drawing style: 2-4 small states, each labeled with a short handwritten annotation.

### Conceptual Metaphor

Best for: Content factory, information warehouse, mental blackbox, workflow machine, automated reporter.
Drawing style: One large, strange object or machine. Minimal input, single output. Make it memorable.

### Method Stack / Hierarchy

Best for: Methodological frameworks, system layers, capability stacks, hierarchical content systems.
Drawing style: Stacked boxes (avoid formal pyramids). Xiaohei can be laying bricks or building the stack.

### Map / Route

Best for: Ideation to production, user journey, content pipeline, learning roadmap.
Drawing style: A curved path with a few key nodes, with Xiaohei pulling a line or walking along.

### Mini-Comic Panels

Best for: Failure to success, real-life workflow struggles, venting, before-after changes.
Drawing style: 2-4 small panels, each showing exactly one action.

## Generating Original Metaphors

Invent a new metaphor for each article; do not reuse old compositions.

### The Three-Step Method

1. Turn the abstract concept into a physical action: Stuck, leaking, weighing down, sorting, settling/filtering, opening a door, folding, unpacking, feedback looping.
2. Replace the system architecture with a low-tech object: A broken machine, cardboard boxes, drawers, water pipes, mailboxes, a strange gauge/dial, scales, a well, a ladder, a weird workstation.
3. Make Xiaohei the active agent: Instead of standing on the side, Xiaohei is stuck inside the machine, pulling the wrong wires, guarding the door, carrying loads, patching holes, weighing items, holding the ladder, writing logs, or stuffing things into a strange device.

### Visual Object Pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, water pipes, balls of yarn, gates, rotary dials, black boxes, hole punchers, pasta makers, clotheslines, weird workstations.
- Use only 1-2 elements in an image; do not clutter the canvas.

### Xiaohei Action Pool

- Pulling, carrying, stuffing, scooping, pressing, weighing, sewing, cutting, tightening, guarding, pushing, catching, dismantling, labeling, recycling.
- Actions must serve the core message, not just be strange for the sake of it.

## Non-Repetition Rules

Do not automatically copy or reproduce the images in `assets/examples/`. Those images are strictly for style calibration (line density, white space, color restraint, Xiaohei's personality).

Unless the user explicitly asks to "recreate this composition", do not reuse these classic layouts:

- Conveyor belt with two breakpoints
- Xiaohei pulling a lever inside a content machine
- Xiaohei acting as a funnel sorting traffic/trust/conversions
- Xiaohei slicing up a "material fish"
- Xiaohei pulling a route path
- Xiaohei gathering three layers of information sources
- Three Xiaoheis holding a megaphone, building a bridge, and opening a door
- Xiaohei stamping blocks at a copy tool station
- Xiaohei holding up a warning sign looking at a roadmap of pitfalls

Invent new metaphors for similar topics. For example, for a "path/funnel", instead of a route, show Xiaohei tying the tail of the content to a doorknob; for "repurposing/multi-use", instead of a fish, show Xiaohei pressing a ball of paper into different molds.

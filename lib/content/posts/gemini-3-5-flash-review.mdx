<aside>

## What is Gemini 3.5 Flash?

Gemini 3.5 Flash is the first model in Google's **Gemini 3.5** family, announced at Google I/O 2026 and made generally available on **May 19, 2026**. Google's framing is deliberate: *"frontier intelligence with action."* It is not pitched as the smartest model on every reasoning leaderboard — it's the model built to **do things**: drive agents, write and verify code, and run long-horizon workflows at a speed and cost that make those things economical at scale. You can try it free in the [Gemini app](https://gemini.google.com/) or build with it in [Google AI Studio](https://aistudio.google.com/).

A few things make this release notable:

- It is a **Flash-tier** model that outperforms the previous generation's **Pro** model ([Gemini 3.1 Pro](/blog/google-antigravity-2-0-review-2026)) on most coding and agentic benchmarks.
- It was built for the **agentic era** — sub-agent deployment, multi-step workflows, and rapid agentic loops are first-class use cases, not afterthoughts.
- Google says **3.5 Pro** is already in internal use and ships next.

<aside>
**Plain-English analogy:** If Gemini 3.1 Pro was a careful senior engineer who thinks before every move, Gemini 3.5 Flash is a brilliant junior who types at 200 words per second. It gets an astonishing amount done in a short time — but you need to review its work, and it'll happily burn through your budget if you let it run unsupervised.
</aside>

| CharXiv Reasoning | 84.2% | — | — | — | — |

**How to read this:**

- **Agentic / tool use is where it wins outright.** It tops the table on **MCP Atlas (83.6%)**, **Toolathlon (56.5%)**, and **MMMU-Pro (83.6%)** — beating Gemini 3.1 Pro, Claude Opus 4.7, and GPT-5.5. If your work is [agents calling tools and MCP servers](/blog/agentic-workflows-n8n), this is the standout result.
- **Coding is strong but not the outright king.** On Terminal-bench 2.1 (76.2%) it edges past 3.1 Pro and Opus 4.7 but trails GPT-5.5 (78.2%). On SWE-Bench Pro (55.1%) it sits behind both Opus 4.7 and GPT-5.5 — Opus is still the heavyweight for hard, single-shot software engineering.
- **It is a massive jump over Gemini 3 Flash.** Across the board the deltas vs the prior Flash are large (e.g., MCP Atlas 62% → 83.6%, Blueprint-Bench 0% → 33.6%).

Third-party data backs this up. On the **[Appwrite Arena](https://appwrite.io/)** backend benchmark it scored **90.70 overall** and finished in **13 minutes — the fastest model in the entire 90+ point top tier**, at $1.14 per run. [Artificial Analysis](https://artificialanalysis.ai/) pegs its Intelligence Index at **50**, comfortably above the ~29 median for its price tier.

<aside>
**Verdict on benchmarks:** Best-in-class for agentic/MCP and multimodal; top-3 for coding; not the best for the hardest single-shot software-engineering tasks. For its price tier, the intelligence-per-dollar is exceptional — on paper.
</aside>

## Speed: this is the headline, and it's real

Google claims Gemini 3.5 Flash is **4x faster** than other frontier models in output tokens per second. In my testing this was not marketing fluff. Independent measurements put it at roughly:

- **~150 tokens/second** on the Artificial Analysis "high" configuration
- **~127 tokens/second** on OpenRouter's throughput test
- **~280 tokens/second** as Google's stated floor-speed target

What that *feels* like: I asked it to generate six different payment-UI variations, and it produced all six in under a minute. Spinning up multi-agent loops in [Antigravity](/blog/google-antigravity-2-0-review-2026), the models finished faster than I could read their output. One developer on LinkedIn put it perfectly: *"the Human is now officially the bottleneck — reviewing the output takes more time than it took the model to generate it."*

## Pricing: the part nobody puts on the marketing slide

This is the most important section of the review, so don't skip it.

| Cost component | Gemini 3 Flash (previous) | Gemini 3.5 Flash (new) |
| --- | --- | --- |
| Input (per 1M tokens) | $0.50 | $1.50 |
| Output (per 1M tokens, incl. thinking) | $3.00 | $9.00 |
| Context caching | — | $0.15 |
| Effective change | baseline | ~3x more expensive |

The sticker price tripled. But the *real* cost is worse than the sticker, because Gemini 3.5 Flash thinks more and outputs more. A widely-shared r/LLMDevs post (flagged by Simon Willison) ran the **same Artificial Analysis benchmark suite** on both models:

![Token cost comparison showing 5.5x real cost difference](/blog/gemini-3-5-flash-review/02-token-cost.svg)

<aside>
**The bill that went viral:** Completing the Artificial Analysis benchmark suite cost **~$278 on Gemini 3 Flash** but **$1,551 on Gemini 3.5 Flash** — roughly **5.5x more**, despite the headline price being only 3x higher. The extra came from the model generating far more thinking + output tokens. *"Everyone's hyped on Gemini 3.5 Flash, but nobody's talking about the bill."*
</aside>

Multiple Antigravity users echoed this. One on the Google AI dev forum wrote: *"I now know why Gemini 3.5 is called Flash"* — not for speed, but because it burns through token quota faster than any model they'd used, getting **1 issue resolved per usage bar vs 5 issues per bar on the pricier Opus 4.6.** The lesson: **fast + token-hungry can be more expensive than slow + efficient.**

<aside>
**How to control the cost (what worked for me):**

1. **Set thinking effort to `low` or `medium`.** The new default is already `medium` (down from `high`), and `low` was significantly improved for short agentic/coding tasks. Reserve `high` for genuinely hard problems.
2. **Use context caching ($0.15)** for repeated long-context prompts.
3. **Cap output tokens** in your API config so a runaway agent can't dump 60K tokens into the chat.
4. **Route by task:** send cheap, high-volume work to **Gemini 3.1 Flash-Lite** and only escalate to 3.5 Flash when you need the reasoning.
</aside>

## Best real-world use cases

From Google's demos and my own testing, this is where Gemini 3.5 Flash shines:

- **[Agentic automation & MCP workflows](/blog/agentic-workflows-n8n)** — its strongest category. Multi-step tool use, sub-agent orchestration, long-horizon tasks. See the [MCP docs](https://modelcontextprotocol.io/) for protocol details.
- **Rapid prototyping** — generating multiple UI/app variations in seconds to explore options.
- **Codebase modernization** — Google demoed transforming a messy legacy codebase to Next.js via the Antigravity harness.
- **High-volume document processing** — multimodal ingestion of PDFs, images, audio, and video at scale (now available in Make for automations).
- **Builder + player loops** — two agents collaborating in a rapid self-improvement loop (e.g., coding a playable game).
- **Search-grounded answering** — first-party search-as-a-tool and grounding with [Google Search](https://developers.google.com/search/docs/guides/get-started) / Maps.

<aside>
**Where it's NOT the best pick:** ultra-tight-budget high-volume jobs (use Flash-Lite), the very hardest single-shot engineering (use Opus 4.7 / GPT-5.5), creative roleplay/long-form fiction, and anything needing Computer Use (not supported yet).
</aside>

## How to use Gemini 3.5 Flash (step-by-step)

### Option 1 — Free, no code (Gemini app / AI Studio)

- Try it in 60 seconds
    1. Open the **Gemini app** or **AI Mode in Google Search** — 3.5 Flash is free for everyone there.
    2. For building/prototyping, go to **Google AI Studio**, pick `gemini-3.5-flash` from the model dropdown, and start prompting. The free tier has no charge for input/output (with rate limits).
    3. Adjust the **thinking effort** (low / medium / high) to trade speed for depth.

### Option 2 — [Gemini API](https://ai.google.dev/gemini-api/docs) (developers)

- Get an API key and make your first call
    1. In [**Google AI Studio**](https://aistudio.google.com/), create an **API key** and set it as an environment variable.
    2. Install the [Google Gen AI SDK](https://github.com/googleapis/python-genai) for your language (Python, TypeScript, Go, Java, etc.).
    3. Call the model with ID `gemini-3.5-flash`. Minimal Python example:

```python
from google import genai

client = genai.Client()  # reads GEMINI_API_KEY from env

response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="Summarize this quarterly report and list 3 risks.",
    config={
        "thinking_config": {"thinking_level": "low"},  # control cost!
        "max_output_tokens": 2048,
    },
)
print(response.text)
```

    4. For agentic workloads, Google recommends the new **Interactions API** (built for background tasks and long-running agents), but the GenerateContent API above works for most use cases.
    5. **Migration note:** the default thinking effort changed from `high` to `medium`. If you migrated from Gemini 3 Flash and your bills jumped, this (plus the price change) is why — set it explicitly.

### Option 3 — Inside an agent IDE ([Antigravity](https://antigravity.google/) / Android Studio / Cursor)

- Use it for agentic coding
    1. In [**Google Antigravity**](/blog/google-antigravity-2-0-review-2026) (Google's agent-first IDE), select **Gemini 3.5 Flash** as your model. This is where its sub-agent and long-horizon strengths show best.
    2. **Always write an implementation plan first** and verify it before you let the agent execute — multiple devs report that a solid plan makes the failure rate very low, while skipping it leads to runaway token use.
    3. It's also available in **Android Studio**, **[Cursor](https://cursor.sh/)**, **[OpenRouter](https://openrouter.ai/)**, and **[Make](https://www.make.com/)** for automation workflows.

## Final verdict

<aside>
**Gemini 3.5 Flash — 4.2 / 5.** Google delivered on the promise of "frontier intelligence with action." For agentic automation, MCP workflows, multimodal tasks, and rapid prototyping, it is the best speed-to-intelligence ratio on the market right now, and it genuinely outperforms last generation's Pro model. The one thing standing between it and a near-perfect score is the **cost behavior**: between the 3x price hike and its appetite for thinking/output tokens, an unsupervised agent can get expensive fast. Treat it as a high-performance power tool — give it a plan, cap its effort, watch the meter — and it's outstanding. Let it run wild and your invoice will remind you why they call it *Flash*.
</aside>
